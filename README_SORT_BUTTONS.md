# 📊 راهنمای دکمه‌های سورت در AlphaScanner

## ✅ تغییرات انجام شده

### ۱. فایل `Trigger.py`
سه تابع جدید اضافه شد:

#### `send_telegram_message(text, chat_id=None, reply_markup=None)`
- پارامتر `reply_markup` اضافه شد تا بتوان کیبورد Inline به پیام‌ها اضافه کرد

#### `build_sort_keyboard(scan_id: str) -> dict`
- کیبورد Inline با سه دکمه می‌سازد:
  - 📊 Sort by Volume
  - ⚠️ Sort by Risk
  - 🏛️ Sort by Market Cap

#### تغییر در تابع `run()`
- تولید `scan_id` یکتا برای هر اسکن
- ارسال کیبورد سورت همراه با آخرین پیام نتایج

### ۲. فایل `telegram_sort_bot.py` (ربات جدید)
یک ربات تلگرام کامل برای مدیریت دکمه‌های سورت:

#### ویژگی‌ها:
- مدیریت کلیک روی دکمه‌های سورت
- سورت کردن نتایج بر اساس:
  - **Volume**: حجم معاملات (زیاد به کم)
  - **Risk**: درصد ریسک (کم به زیاد)
  - **Market Cap**: ارزش بازار (بزرگ به کوچک)
- نمایش داده‌های نمونه برای تست
- راهنمای کامل

#### دستورات ربات:
- `/start` - شروع و نمایش منو
- `/test` - تست با داده‌های نمونه
- دکمه‌های Inline برای سورت

## 🔧 نحوه استفاده

### مرحله ۱: اجرای Trigger.py
```bash
python3 Trigger.py
```
این فایل:
1. بازار را اسکن می‌کند
2. نتایج را به تلگرام ارسال می‌کند
3. زیر آخرین پیام، ۳ دکمه سورت نمایش می‌دهد

### مرحله ۲: مدیریت دکمه‌ها
وقتی کاربر روی دکمه‌ها کلیک می‌کند:
- `Callback data` به فرمت `sort_volume_{scan_id}` ارسال می‌شود
- ربات `telegram_sort_bot.py` باید در حال اجرا باشد تا این کلیک‌ها را مدیریت کند

### مرحله ۳: اجرای ربات سورت
```bash
python3 telegram_sort_bot.py
```

## 📝 نکات مهم

1. **ذخیره‌سازی نتایج**:
   - در حال حاضر نتایج در حافظه موقت (`LAST_SCAN_RESULTS`) ذخیره می‌شوند
   - برای محیط پروداکشن، بهتر است از Redis یا دیتابیس استفاده کنید

2. **scan_id**:
   - هر اسکن یک `scan_id` یکتا دارد (۸ کاراکتر اول UUID)
   - این شناسه در callback_data دکمه‌ها استفاده می‌شود

3. **یکپارچگی با Trigger.py**:
   - ربات سورت به صورت مستقل کار می‌کند
   - برای اتصال کامل، باید نتایج اسکن بین دو ربات به اشتراک گذاشته شود

## 🧪 تست

1. ربات سورت را اجرا کنید:
```bash
python3 telegram_sort_bot.py
```

2. در تلگرام `/start` را بزنید

3. روی "🧪 نمایش نتایج نمونه" کلیک کنید

4. حالا روی دکمه‌های سورت کلیک کنید و نتیجه را ببینید

## 📋 ساختار Callback Data

- `sort_volume_{scan_id}` - سورت بر اساس حجم
- `sort_risk_{scan_id}` - سورت بر اساس ریسک
- `sort_mcap_{scan_id}` - سورت بر اساس مارکت کپ

## 🔐 امنیت

- توکن‌ها hardcoded هستند - فقط برای تست محلی
- برای پروداکشن، از environment variables استفاده کنید
- محدودیت Rate Limit (۶۰ ثانیه بین درخواست‌ها)
